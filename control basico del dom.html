Consigna: resolver los siguientes ejercicios con JavaScript y explicar el código utilizado en cada uno.

1. Párrafo que alterna entre dos frases

Tocame para cambiar de frase

¿Por qué usé lo que usé? Usé textContent porque solo necesito cambiar el texto plano del párrafo, no agregar etiquetas HTML nuevas (para eso existiría innerHTML, pero no hace falta acá y además es menos seguro si el texto viniera de un usuario). Usé click (con el atributo onclick) porque el cambio tiene que pasar cada vez que el usuario toca el párrafo o el botón, no solo, una vez.

¿Para qué sirve cada función/método? document.getElementById() busca el elemento del DOM por su id para poder modificarlo. La variable fraseActual guarda en qué frase estoy parado, y se usa un operador ternario para "alternar" entre 0 y 1 cada click.

¿Hay más formas de hacerlo? Sí. Podría usar addEventListener("click", ...) en vez de onclick en el HTML (es más prolijo porque separa el JS del HTML). También podría guardar un booleano true/false en vez de un número, o usar el operador módulo fraseActual = (fraseActual + 1) % 2 para alternar.

2. Contador simple

Valor: 0

¿Por qué usé lo que usé? Necesito una variable (contador2) porque el número tiene que "recordarse" entre un click y otro; si lo definiera adentro de la función se reiniciaría siempre en 0. Uso textContent para mostrar ese número actualizado dentro del <span>, y click para disparar la suma.

¿Para qué sirve cada función/método? let declara una variable que puede cambiar de valor (a diferencia de const). textContent reemplaza el contenido de texto del elemento por el valor actual del contador cada vez que se ejecuta la función.

¿Hay más formas de hacerlo? Sí, podría usar el operador de incremento contador2++ en vez de contador2 = contador2 + 1, que hace exactamente lo mismo pero más corto. También podría guardar el contador como un atributo data-valor en el HTML en vez de una variable de JS.

3. Título con frase al azar

Frase al azar

¿Por qué usé lo que usé? Uso un array (listaFrases) porque necesito guardar varias frases juntas y poder elegir una de ellas por su posición (índice). Uso Math.random() porque es la forma que tiene JavaScript de generar un número al azar.

¿Para qué sirve cada función/método? Math.random() devuelve un decimal entre 0 (incluido) y 1 (no incluido). Lo multiplico por listaFrases.length (la cantidad de frases) para obtener un número entre 0 y 5 (sin llegar a 5). Math.floor() redondea ese decimal para abajo y así obtengo un índice válido del array (0 a 4).

¿Hay más formas de hacerlo? Sí, podría usar Math.trunc() en vez de Math.floor() (con números positivos dan el mismo resultado). También se podría armar una función genérica que reciba cualquier array y devuelva un elemento al azar, para reutilizarla en otros ejercicios.

Valor: 0

¿Por qué usé lo que usé? Uso un condicional (if) en la función de restar porque tengo que controlar que el contador nunca sea negativo: antes de restar, pregunto si el contador es mayor a 0. En la función de sumar no hace falta condición porque no hay límite para arriba.

5. Alert con el texto de un input

¿Por qué usé lo que usé? Uso .value porque es la propiedad que guarda lo que el usuario escribió adentro de un <input> (no es lo mismo que textContent, que se usa para elementos que muestran texto, no para campos de formulario). Uso alert() porque la consigna pide mostrar el texto en una ventana emergente.

¿Para qué sirve cada función/método? document.getElementById("input5").value lee el contenido actual del input en el momento del click. alert(texto) abre una ventana del navegador con ese texto adentro.

¿Hay más formas de hacerlo? Sí, en vez de alert() podría mostrar el texto dentro de un párrafo de la página con textContent, que es menos molesto para el usuario que una ventana emergente. También podría escuchar el evento input para mostrar el texto en vivo, mientras el usuario escribe.

6. Botón que cambia su propio texto

¿Por qué usé lo que usé? Uso un condicional para preguntarle al propio botón qué texto tiene en este momento (con textContent) y así decidir a qué texto cambiarlo: es una forma de "toggle" (interruptor) sin necesitar una variable aparte, porque el estado queda guardado en el mismo texto del botón.

¿Para qué sirve cada función/método? boton.textContent === "Activar" compara el texto actual del botón con la palabra "Activar". Según el resultado (verdadero o falso), el if/else decide si pone "Desactivar" o vuelve a poner "Activar".

¿Hay más formas de hacerlo? Sí, podría guardar el estado en una variable booleana (let activado = false;) en vez de leer el texto del botón, lo cual es más prolijo si después quiero usar ese estado en otra parte del código. También se podría usar un atributo data-estado en el HTML para guardar "activo" o "inactivo".

7. Investigación: DOM y estados

¿Qué es el DOM? El DOM (Document Object Model / Modelo de Objetos del Documento) es una representación en forma de "árbol" de todos los elementos de una página HTML (etiquetas, textos, atributos). El navegador arma ese árbol cuando carga la página, y JavaScript puede usar ese árbol para leer, agregar, borrar o modificar cualquier parte de la página sin tener que recargarla.

¿Qué son los estados? Un estado es el valor que tienen en un momento dado los datos que controlan cómo se ve o se comporta la página (por ejemplo: el número de un contador, si un botón está "activado" o no, el texto que está guardado en una variable). En los ejercicios anteriores, cosas como contador2, contador4 o el texto del botón 6 son estados: van cambiando con cada interacción del usuario, y la página se actualiza para reflejar ese cambio.

¿En qué nos ayuda manipular el DOM con JS? Nos permite que la página sea interactiva y dinámica: podemos cambiar textos, estilos, mostrar u ocultar elementos, validar formularios, reaccionar a clicks, etc., todo sin tener que recargar ni pedir una página nueva al servidor. Es lo que hace que un sitio web deje de ser algo estático (como un afiche) y se convierta en una aplicación con la que el usuario puede interactuar en tiempo real.
