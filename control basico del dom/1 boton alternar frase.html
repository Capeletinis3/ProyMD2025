1. Párrafo que alterna entre dos frases

Tocame para cambiar de frase

Explicación

¿Por qué usé lo que usé? Usé textContent porque solo necesito cambiar el texto plano del párrafo, no agregar etiquetas HTML nuevas (para eso existiría innerHTML, pero no hace falta acá y además es menos seguro si el texto viniera de un usuario). Usé click (con el atributo onclick) porque el cambio tiene que pasar cada vez que el usuario toca el botón, no solo una vez.

¿Para qué sirve cada función/método? document.getElementById() busca el elemento del DOM por su id para poder modificarlo. La variable fraseActual guarda en qué frase estoy parado, y se usa un operador ternario para "alternar" entre 0 y 1 cada click.

¿Hay más formas de hacerlo? Sí. Podría usar addEventListener("click", ...) en vez de onclick en el HTML (es más prolijo porque separa el JS del HTML). También podría guardar un booleano true/false en vez de un número, o usar el operador módulo fraseActual = (fraseActual + 1) % 2 para alternar.
