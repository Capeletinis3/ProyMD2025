5. Alert con el texto de un input

Explicación

¿Por qué usé lo que usé? Uso .value porque es la propiedad que guarda lo que el usuario escribió adentro de un <input> (no es lo mismo que textContent, que se usa para elementos que muestran texto, no para campos de formulario). Uso alert() porque la consigna pide mostrar el texto en una ventana emergente.

¿Para qué sirve cada función/método? document.getElementById("input5").value lee el contenido actual del input en el momento del click. alert(texto) abre una ventana del navegador con ese texto adentro.

¿Hay más formas de hacerlo? Sí, en vez de alert() podría mostrar el texto dentro de un párrafo de la página con textContent, que es menos molesto para el usuario que una ventana emergente. También podría escuchar el evento input para mostrar el texto en vivo, mientras el usuario escribe.
